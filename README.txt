# EduDiary — Academic Planner

## Запуск
1. Распакуйте архив.
2. Откройте папку EduDiary в Visual Studio Code.
3. Запустите `index.html` через расширение Live Server.

## Что уже работает
- Адаптивная главная страница в графитово-пудровой палитре.
- Создание и удаление предметов.
- Добавление оценок от 1 до 5.
- Переключение между триместрами и семестрами.
- Подсчёт среднего балла и количества оценок.
- Простой прогноз и расчёт требуемых будущих оценок.
- Локальное сохранение данных в браузере через localStorage.

## Важно
Это пока front-end прототип. Данные хранятся локально в браузере на одном устройстве. Регистрация, личные аккаунты и общая облачная база данных будут добавлены отдельным этапом с Firebase.

## Шрифт Lairé Sans
В CSS уже настроено локальное подключение Lairé Sans.
1. Скачайте файл шрифта со страницы https://fonts-online.ru/fonts/laire-sans
2. Положите файл в папку `fonts`.
3. Назовите его `LaireSans.woff2` или `LaireSans.ttf`.
4. Обновите страницу сайта.

Пока файл шрифта не добавлен, браузер использует системный шрифт-запасной вариант.
Проверьте лицензию у правообладателя перед публикацией сайта; на странице каталога указано персональное использование.
